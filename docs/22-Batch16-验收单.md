# Batch16 验收单 —— 并发配额下发审计（append-only）

- **迁移**：`v008_worker_quota_audit`（新建表，不动注册表、不动台账两表）
- **接口面**：**10 个路径不变** —— 审计只落库 + CLI 读，没开接口
- **新增**：`worker_quota_audit` 表、`scripts/quota_audit.py`

## 为什么

Batch15 之后，注册表里只有一个"当前期望值"。运维事后问"这个实例的配额被谁动过、从几改到几"时，只能翻日志，而日志会被轮转。审计表把这件事固化成数据。

## 规则

- 每次 `master:worker-limit` 落一行：目标、新值、旧值、原因、时间
- 与注册表更新**在同一事务**：不会出现"配额改了但没留痕"
- **只追加**：不更新、不删除；同一实例下发多次就是多行
- 铁律同台账：审计行不可删（`ci.py` 会扫代码里有没有删改审计的语句）
