## 背景

平台有看板能看「现在」，但没人盯着的时候「昨天下午三点是什么样」就查不到。
Batch26 做过前端「存快照」（单文件 HTML），那是手点的。这一批要做**离线生成**：
用 Python 拉平台接口，生成一张单文件 HTML，可以每天定时跑、可以发给人看、可以存档。

## 铁律（违反即不验收）

1. **只允许新增这两个文件**：
   - `scripts/daily_snapshot.py`
   - `docs/base/14-每日快照.md`
2. **不许修改任何已有文件**（`git status` 里除了上面两个 `??`，出现的其它任何改动都是失败）。
3. 不 commit、不 push。
4. 只用**标准库**（`urllib.request`、`json`、`html`、`argparse`、`datetime`、`os`、`tempfile`、`re`）。
   **不许 import** `requests`、`fastapi`、`sqlalchemy`、`app.*`、`worker.*` —— 这个脚本要能在没装项目依赖的机器上直接跑。
5. 接口面不许扩张：只用现有的 11 个路径。

## `scripts/daily_snapshot.py` 要求

命令行：

```
python3 scripts/daily_snapshot.py --base-url http://127.0.0.1:8000 --out data/snapshots/2026-11-21.html
python3 scripts/daily_snapshot.py --selftest      # 不联网，用内置样例数据自检
```

参数：

- `--base-url`（默认 `http://127.0.0.1:8000`）
- `--token`（默认读环境变量 `API_TOKEN`，没有则空串，对应平台不开鉴权的情形）
- `--out`（默认 `data/snapshots/<今天 YYYY-MM-DD>.html`）
- `--pipeline-limit`（默认 50）
- `--audit-limit`（默认 20）
- `--selftest`：用内置样例数据渲染到临时文件，逐条断言，打印 `[PASS]/[FAIL]`，失败时退出码 1
- `--selftest` 之外，正常模式：拉 `GET /api/pipelines`、`GET /api/workers`、`GET /api/audit`，渲染 HTML，打印一行 `已生成：<绝对路径>（流水线 N 条 / 执行方 M 个 / 审计 K 条）`

取数细节：

- 三个请求都带 `X-API-Token: <token>`（token 为空就不带这个头）
- 任一路接口非 200 → 打印 `[FAIL] GET /api/pipelines => 401` 这类信息并 **退出码 2**，不要静默生成半张空页面
- 401/403 时的提示要直白：`口令不对或没给（看板右上角那枚 API_TOKEN）`

HTML 要求（单文件，无外链、无 JS 依赖、离线可看）：

- `<meta charset="utf-8">`、`<title>台账快照 · <日期> · <生成时间>`
- 内联 `<style>`，**台账视觉**：接近纸色底（`#f7f4ee` 一类）、正文近黑、2px 墨线分隔、表格头双线、数值右对齐、等宽字体用于时间与数字
- 三个区块，按顺序：**流水线**（trace_id / 状态 / 开始 / 结束 / 是否停滞）、**执行方**（worker_id / 实例 / 状态 / 并发 / 限额 / 最近上报 / 心跳秒数）、**运维审计**（时间 / 操作者 / 动作 / 目标 / 旧→新 / 是否生效）
- 状态用文字 + 颜色（`success` 绿、`failed` 红、`pending` 灰、`running` 深色），**不要只靠颜色区分**（要写字）
- 停滞判定：状态仍是 `pending`/`running` 且开始时间超过 10 分钟 → 显示「停滞」并标红
- 页脚一行：`生成时间 <本地时间>　数据来源 <base-url>　共 N 条`
- 所有插值必须 `html.escape`（这条要在 selftest 里验一条：样例数据里放 `<script>alert(1)</script>`，渲染后必须看不到裸 `<script>`）

`--selftest` 至少覆盖 8 条断言：

1. 样例数据渲染成功、文件已落盘
2. HTML 含 `<meta charset="utf-8">`
3. 含三个区块标题（流水线 / 执行方 / 运维审计）
4. 含 `停滞` 字样（样例里特意放一条超 10 分钟未结束的）
5. 含执行方的 `online` 与心跳秒数
6. 审计行里能看到「旧→新」
7. XSS 场景被转义（渲染结果里不出现 `<script>alert(1)</script>` 原文）
8. 生成时间与日期出现在标题/页脚
