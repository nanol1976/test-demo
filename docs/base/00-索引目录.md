## 平台层不做什么（边界，别越界）

- 不实现 DAG 拆解（属 Master 职责，平台只做"依赖满足才允许派发"的闸门）
- 不做 Schema 校验（只校验协议必带字段与类型）
- 不做验收判定（不做"产出好不好"的判断）
- 不做审批决策（高危卡点只留痕，决策权在人/Master）
- 不删数据（台账只追加与状态更新）
