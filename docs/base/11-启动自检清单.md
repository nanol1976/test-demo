# 11 · 启动自检清单

上线前逐项打勾。任何一项 ❌，不启动。

## A. 环境

- [ ] Python 3.11+ 可用（Windows 用 `.venv311\Scripts\python.exe`）
- [ ] 依赖装齐：`pip install -r requirements.txt`（含 **uvicorn**——Mac 曾漏装，服务起不来报 `No module named uvicorn`）
- [ ] `PYTHONPATH` 指向工程根（否则 `No module named 'app'`）
- [ ] 目录可写：`data/`、`archive/`

## B. 配置（`.env`）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `DATABASE_URL` | `sqlite:///./data/mvp.db` | 库地址 |
| `ARCHIVE_ROOT` | `./archive` | JSONL 归档根 |
| `API_TOKEN` | 空 | 空=不校验；设了必须带 `X-API-Token` |
| `BUS_CAPACITY` / `BUS_WORKERS` | 适中值 | 队列容量 / worker 数 |
| `TASK_TIMEOUT_SECONDS` | 3600 | 派发超时 |
| `HEARTBEAT_TIMEOUT_SECONDS` | 120 | 心跳告警阈值 |
| `FAILURE_THRESHOLD` | 3 | 熔断阈值 |
| `SCAN_INTERVAL_SECONDS` | 5.0 | 后台扫描间隔 |
| `PAGE_SIZE_DEFAULT` / `PAGE_SIZE_MAX` | 20 / 100 | 分页 |

- [ ] 生产环境**必须**设 `API_TOKEN`（空令牌等于裸奔）
- [ ] 时间相关阈值与业务节奏匹配（超时别小于正常任务耗时）

## C. 库

- [ ] 表存在：`pipeline_ledger` / `task_ledger` / `message_archive`
- [ ] 缺表时启动会自动补建并告警（`ensure_schema`）——**看到告警要确认这不是生产库**
- [ ] 三条 CHECK 约束在（pipeline 5 值 / task 7 中文值 / sender 5 值）
- [ ] 唯一约束 `uq_archive_message(trace_id, task_id, msg_type, timestamp)` 在
- [ ] 库里**没有测试数据**（`init_db.py` 不写测试数据）

## D. 启动后验证（真实起服务，不是 TestClient）

```bash
# 1. 健康
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8000/api/health       # 期望 200

# 2. 首页
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8000/                 # 期望 200

# 3. 静态资源
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8000/static/app.js    # 期望 200

# 4. 空列表不报错
curl -s "http://127.0.0.1:8000/api/pipelines?page=1&size=5"                     # 期望 meta.total=0

# 5. 鉴权（设了 API_TOKEN 时）
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8000/api/pipelines     # 期望 401
curl -s -o /dev/null -w "%{http_code}\n" -H "X-API-Token: $API_TOKEN" http://127.0.0.1:8000/api/pipelines  # 期望 200

# 6. 投一条探针报文
# 期望 202
```

一键版：`python scripts/smoke_http.py`（自动起服务、跑上面 6 项、关服务、给结论）

## G. 已知遗留（上线要知情）

- 熔断状态在**进程内存**，重启复位
- 心跳超时**只告警不杀任务**
- DAG 只做「依赖满足才允许派发」，不做拓扑排序与并行度控制
- 令牌存前端 `localStorage`（XSS 面已压低，正式部署建议 HttpOnly Cookie）
- 看板无自动刷新

## H. Windows 计划任务（Batch23）

- [ ] 装：`powershell -NoProfile -ExecutionPolicy Bypass -File deploy\install-windows-tasks.ps1 -StartTasks`（普通用户即可，不需要管理员）
- [ ] 三个任务都在：`Get-ScheduledTask -TaskName 'MW-*' | Format-Table TaskName, State` → `MW-Platform` / `MW-Worker` = Running，`MW-Watchdog` = Ready
- [ ] 动作是隐藏启动器：`(Get-ScheduledTask -TaskName 'MW-*').Actions` → `wscript.exe //nologo ...\deploy\launch-*-hidden.vbs`
- [ ] 结果码含义：`0` 正常；`0x41301` 表示任务正在运行（正常）；`0x800710E0` 表示"已有实例在跑、拒绝再起一份"（常驻任务正常现象，不是故障）
- [ ] `run\worker-run.bat` 存在（`launch-worker-hidden.vbs` 缺它会直接报错退出）
- [ ] 拆：`... install-windows-tasks.ps1 -Uninstall`（只注销任务，不删仓库文件）
