## L. 手机 / 局域网访问（Batch27）

平台默认仍只绑 `127.0.0.1`（本机可见）。要手机看，改动只有一处：平台启动器 `deploy\launch-platform-hidden.vbs` 里传 `-Bind 0.0.0.0`，`deploy\run.ps1` 本身默认值不动——**换一台机器不会默认对外**。

前置条件（顺序不能反）：

1. `.env` 里有 `API_TOKEN`（`.env` 在 gitignore 里，token 不进版本库）。空 token 等于不校验，同网段谁都能点「暂停派发」「下发配额」。
2. Worker 必须带同一个 token：`deploy\install-windows-tasks.ps1` 会自动从 `.env` 读 `API_TOKEN` 拼进 `run\worker-run.bat`。**加了 token 但没重跑安装脚本 → Worker 立刻 401 掉线**，这是最容易漏的一步。
3. 防火墙放行 8000 入站（要管理员）。本机现状是「专用网络」配置文件被关闭，所以没被拦；换到防火墙开启的网络时，先跑：
   `New-NetFirewallRule -DisplayName 'MW-Platform 8000' -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private`

手机端：连同一个 Wi-Fi → 浏览器开 `http://<本机局域网IP>:8000/` → 页面顶部「X-API-Token」填 `.env` 里那串 → 点「记住」（存本机 localStorage，下次不用重填）。

- [ ] `Get-NetTCPConnection -LocalPort 8000 -State Listen` 的 LocalAddress 是 `0.0.0.0` 才算绑对
- [ ] 手机不填 token 时，页面会显示「加载失败：401」——那不是坏了，是鉴权生效
- [ ] 别做公网端口映射 / 内网穿透：那等于把运维控制台挂到公网
- [ ] 只想偶尔看一眼，不必开局域网：「存快照」下载的单文件 HTML 发到手机即可，离线也能看

### 只读口令（能看不能动）

一枚口令通吃的问题是：手机里存着它，被看到一次就等于交出「暂停派发 / 改并发配额」的权限。所以拆两档：

| 环境变量 | 权限 | 用在哪 |
|---|---|---|
| `API_TOKEN` | 全权（读 + 写） | 电脑上自己用；Worker 上报也用这一枚 |
| `API_TOKEN_READONLY` | 只读（只能 GET） | 手机、外发查看 |

`.env` 里加一行 `API_TOKEN_READONLY=<另一串随机值>` 重启平台即生效。三条写接口（`POST /api/messages`、`POST /api/commands`、`POST /api/workers`）在服务端直接 403，不靠前端藏按钮；看板收到响应头 `X-API-Mode: readonly` 时会在标题旁亮一枚「只读」章，并把暂停／恢复／复位／投递按钮置灰。

- [ ] 只读口令读 `/api/pipelines`、`/api/workers`、`/api/audit` 应 200，且响应头带 `X-API-Mode: readonly`
- [ ] 同一枚只读口令 POST `/api/commands` 应 403（不是 401）
- [ ] 全权口令不受影响，POST 仍 200/202
- [ ] `API_TOKEN_READONLY` 留空 = 不启用只读档（此时只有全权一枚，行为同 Batch27）
- [ ] 两枚口令都要写进 `.env`（gitignored），不要写进任何脚本或文档
