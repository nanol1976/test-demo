# 14. 每日快照生成器

## 是什么

`scripts/daily_snapshot.py` 是一个**离线生成**工具，它调用平台的三个只读接口（`/api/pipelines`、`/api/workers`、`/api/audit`），把当天的台账数据渲染成一份**单文件 HTML**，无任何外部依赖、无 JavaScript、离线可直接用浏览器打开。

生成的 HTML 采用「台账」视觉语言：纸色底（`#f1f2ec`）、2px 墨线分隔、表头双线、数值右对齐、等宽字体用于时间与数字、状态用「文字 + 颜色」双重标注（不只靠颜色区分）。

## 为什么要

- **离线存档**：平台有看板能看「现在」，但没人盯着的时候「昨天下午三点是什么样」就查不到。每天跑一次、存一份，形成可追溯的历史台账。
- **发人可看**：单文件 HTML 可直接发给产品、运维、老板，对方不用装环境、不用登录、不用连内网，双击即看。
- **定时自动化**：配合 Windows 计划任务 / Linux cron，每天自动跑、自动落盘，零人工干预。

## 命令怎么敲

```bash
# 正常模式：拉取线上接口生成快照
python3 scripts/daily_snapshot.py \
  --base-url http://127.0.0.1:8000 \
  --out data/snapshots/2026-11-21.html

# 离线自检：不联网，用内置样例数据验证渲染逻辑
python3 scripts/daily_snapshot.py --selftest
```

## 参数表

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--base-url` | 平台基础 URL | `http://127.0.0.1:8000` |
| `--token` | API Token（也可用环境变量 `API_TOKEN`） | 读 `API_TOKEN`，无则空串 |
| `--out` | 输出文件路径 | `data/snapshots/<今天 YYYY-MM-DD>.html` |
| `--pipeline-limit` | 流水线取数上限 | `50` |
| `--audit-limit` | 审计取数上限 | `20` |
| `--selftest` | 离线自检模式（不联网） | 关闭 |

## 退出码含义

| 码 | 含义 |
|----|------|
| `0` | 成功（正常模式生成完成、或自检全部通过） |
| `1` | 自检失败（有断言未通过） |
| `2` | 接口取数失败（非 200、含 401/403） |

## `API_TOKEN` 从哪来

- 平台启动时在 `.env` 里配置的 `API_TOKEN`。
- 看板右上角「X-API-Token」输入框里那枚。
- 脚本优先读 `--token` 参数，其次读环境变量 `API_TOKEN`，都没有则不带鉴权头（对应平台未开启鉴权的情形）。
- **401/403 时提示直白**：「口令不对或没给（看板右上角那枚 API_TOKEN）」。

## 生成物放哪

默认落在 `data/snapshots/YYYY-MM-DD.html`（相对仓库根目录）。
建议把 `data/snapshots/` 加入 `.gitignore`，只做本地存档、不入库。

## 怎么用 Windows 计划任务每天跑一次

以管理员身份打开 PowerShell，执行下面这条命令（把 `<repo>` 换成实际仓库绝对路径，如 `D:\codex-workspace\mwp-b30`）：

```powershell
$repo = "<repo>"
$python = "python3"   # 若不在 PATH，请写完整路径，如 "C:\Python311\python.exe"
$script = "$repo\scripts\daily_snapshot.py"
$outDir = "$repo\data\snapshots"

# 确保输出目录存在
if (-not (Test-Path $outDir)) { New-Item -ItemType Directory -Path $outDir | Out-Null }

# 创建每天 00:05 执行的任务
schtasks /Create /TN "MWB每日快照" ^
  /TR "\"$python\" \"$script\" --base-url http://127.0.0.1:8000 --out \"$outDir\$(Get-Date -Format 'yyyy-MM-dd').html\"" ^
  /SC DAILY /ST 00:05 /RL HIGHEST /F
```

**说明**：
- `/RL HIGHEST` 让任务以最高权限运行，避免写文件受阻。
- `--base-url` 指向本机平台地址；若平台跑在别的机器，改成对应 IP/域名。
- 若平台开启了鉴权，需在任务的「运行时使用的账户」环境变量里配置 `API_TOKEN`，或把 `--token` 直接写进命令（不推荐明文写密钥）。

也可用 `schtasks /Query /TN "MWB每日快照" /V /FO LIST` 查看任务详情，用 `schtasks /Delete /TN "MWB每日快照" /F` 删除。

## ⚠️ 注意
